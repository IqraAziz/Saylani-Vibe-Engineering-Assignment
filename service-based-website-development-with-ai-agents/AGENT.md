# ProFix Services — Home & Business Maintenance

## 1. Website purpose
ProFix Services is a modern home and business maintenance company that helps homeowners, landlords, and small businesses keep properties safe, efficient, and well-maintained. The website exists to build trust, explain available services, convert visitors into booked appointments, and make the service request process simple and fast.

## 2. Target users
- Homeowners who need repairs, maintenance, or urgent fixes
- Landlords and property managers managing multiple properties
- Small business owners needing routine maintenance and upkeep
- Busy professionals seeking dependable local service providers
- Customers looking for transparent pricing, fast response times, and professional support

## 3. Business/service concept
ProFix Services provides reliable, professional maintenance and repair solutions for residential and commercial properties. The business combines skilled trade support, responsive scheduling, and quality service standards with a friendly customer experience.

Core offerings include:
- General home maintenance
- Electrical and plumbing repairs
- HVAC servicing and seasonal tune-ups
- Appliance installation and upkeep
- Office and retail maintenance
- Emergency repair response and property care plans

## 4. Main pages
The website must include these pages:
- Home
- Services
- About
- Contact
- Service Request / Booking

## 5. Core features
- Responsive navigation with a working mobile menu
- Hero section with strong messaging and clear CTAs
- Service cards with descriptions and service categories
- Company/about section highlighting trust, experience, and expertise
- Testimonials section proving customer satisfaction
- FAQ accordion for common support questions
- Contact form with front-end validation
- Booking/service request form with front-end validation
- Success and error messages for user submissions
- Smooth scroll navigation between sections and pages
- Simple motion/animation for cards, sections, and buttons
- Responsive footer with navigation and contact details
- Front-end-only persistence using JavaScript/localStorage for request tracking

## 6. User flow
1. Visitor lands on the home page and quickly understands the business value.
2. User explores available service categories or reads the about page.
3. User clicks a CTA to view services or request a booking.
4. User completes a booking form with service details and preferred schedule.
5. The browser validates inputs and stores the request locally for demo purposes.
6. User sees confirmation feedback and can continue to contact support or explore other pages.

## 7. Design requirements
- Modern, professional, and clean visual style
- Strong use of whitespace, modern typography, and balanced layouts
- Consistent colors, button styles, card design, and spacing across all pages
- High readability and accessible contrast for text and controls
- Mobile-first responsive layout that works across phones, tablets, and desktops
- Consistent branding with a service-trust feeling
- Clear hierarchy for headings, CTAs, service information, and forms

## 8. Development rules for the AI agent
- Use HTML, CSS, and vanilla JavaScript only. No React, no frameworks, no build tools required.
- Use CSS variables for theme values and maintain a clean structure.
- Keep all code organized and reusable across pages where possible.
- Ensure forms validate correctly before submission.
- Use localStorage for mock submission handling since there is no backend.
- Keep navigation and actions fully functional.
- Do not create a mockup-only design; build an interactive frontend with working behavior.
- Every page should feel connected to the same brand and same design system.
- Check for broken links, missing alt text, JavaScript issues, and responsive problems before finishing.
- Maintain accessibility best practices: proper labels, focus states, semantic elements, and readable contrast.

## 9. Brand direction
The website should feel dependable, local, and professional. The tone should communicate expertise, quick response times, and trustworthy home and business support.
